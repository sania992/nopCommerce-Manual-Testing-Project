# nopCommerce Manual Testing Project

## Project Overview

This project demonstrates manual testing of the nopCommerce Demo Store, an e-commerce web application.

The project covers functional testing of major e-commerce modules including user registration, login, product search, product management, checkout, My Account, and Wishlist functionality.

## Application Under Test

**Application:** nopCommerce Demo Store
**Website:** https://demo.nopcommerce.com/

## Modules Tested

* Registration
* Login
* Search
* Product
* Checkout
* My Account
* Wishlist

## Testing Activities

* Created manual test scenarios and test cases
* Executed functional and negative test cases
* Performed boundary-value testing for search functionality
* Verified validation messages
* Tested product, cart, wishlist, checkout and account functionality
* Documented test execution results
* Identified and reported a functional defect
* Reported the defect in Jira
* Maintained a Requirement Traceability Matrix (RTM)
